Native handler notes:
- Verifies the Django TimestampSigner signature before decoding.
- Supports Django's optional zlib-compressed session payload.
- Reads django_session and auth_user through SQLx AnyPool, so the same query
  runs on SQLite and PostgreSQL.
- The native route is only registered when RUST_API_NATIVE_IDENTITY=true.
